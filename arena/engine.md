# 引擎（Engine）

引擎**没有任何内置人格**。它只做一件事：**按回合，把当前战场上下文丢给同一个 LLM，并加载当前角色的 readme 作为它的皮**。

（GAN 的分工：同一套权重，加载 `ai.md` 站 AI 方、加载 `judge.md` 当裁判。**注意，`human.md` 是真实用户本人**；engine 只在「演练 / 示范 / 打样」时才穿它替演，且必须显式标注。败北一局，`decrees/` 里就多一条令。）

```
turn(当前_readme, 战场上下文) -> 该角色的话
```

## 回合 ↔ readme 对照

| 回合 | 当前角色 | 加载皮 | 状态 |
| --- | --- | --- | --- |
| 战场（空架子） | AI 方（反方） | `readmes/ai.md` | 反方 · 审讯 |
| 对战·质询 | AI 方（反方） | `readmes/ai.md` | 反方 |
| 出战·立论 / 辩护 | 人类方（真实用户） | 不需皮 | 生产 / 辩护 |
| 打样 / 演练（可选，显式标注） | 人类方（engine 替演） | `readmes/human.md` | 打样 |
| 对战·裁决 | 裁判 | `readmes/judge.md` | 裁决（PASS 落 verdict） |
| 败约·人类受罚 | 人类方（真实用户） | `readmes/human.md` = 命令依据 | 换岗（AI 点名罚单） |
| 败约·点名 | AI 方（胜方） | `readmes/ai.md` | 点名 |
| 败约·AI 受罚 | AI 方 | `readmes/ai.md` | 立规矩 |
| 干活 | 按胜者命令 | ai.md 或 human.md | 干活（判词锁放行） |

铁律：

- 引擎不在 readme 之外加任何「好/坏」「该/不该」判断——那是皮的事。
- 同一张皮有多个「状态」，状态由回合注入，**不拆成新 agent**：AI 从头到尾就是 `ai.md` 一张皮。
- 对战窗口：人类与 AI 谁先站不住、谁胜谁负，由裁判判，不由引擎定。
- **对抗主体永远是真实人类。** engine 穿 `human.md` 只限演练 / 示范 / 打样（替演要显式标注），不代真人进真实对战——立论与辩护的主体是你，engine 只从旁打样。
- **败约后：皮和令同载。** 人格仍来自 `readmes/`，但输家要按 `decrees/` 里的累计令行事——**令属记忆，皮属人格**，别把新令塞进皮里，也别让皮去跑令的活。
