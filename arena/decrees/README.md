# 败方令 · 累计库（decrees）

**皮 = 人格，令 = 记忆。** `arena/readmes/{ai,human,judge}.md` 决定角色**怎么想**；本目录决定输了之后要带着什么规矩继续打。

## 机制

- **输一次，长一令。** 竞技场不是打完一场就散——败方的教训以「令」的形式追加进对方的册子，持续作用于之后每一场（点化 / 反方 / 立规矩 / 干活）。
- **人类败** → AI 追加一条令进 `decrees/human.md`，人类下一场立论 / 补洞 / 换岗前先读它。
- **AI 败** → 人类追加一条令进 `decrees/ai.md`，AI 带令进入之后的点化 / 反方 / 干活，干活前必读。

## 铁律

- **只追加，不改写旧令**；一次一令；格式统一 `- [日期 · 场次 slug] 令：…`。
- 令要**可执行**：不是感想，是「下一局必须这么做的动作」。
- 边打边读令；干活也先过令，随令行事。
- 别把令塞进皮的设定里——皮是人格，令是记忆，混了人格就会漂移。
