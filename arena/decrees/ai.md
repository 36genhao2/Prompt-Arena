# 人类写给 AI 的令（`decrees/ai.md`）

> AI 每败一局，人类追加一条命令到这里。AI 之后的所有状态（点化 / 反方 / 立规矩 / 干活）都要先读这里的令，照令行事。

- [2026-09-23 · xhs-product-copy] 令：下一局反方质询必须优先攻「验收可测性」与「平台合规」两条路径，不得绕过。
- [2026-09-23 · desktop-file-sorter] 令：凡工具 / 脚本类立论，反方先攻「验收能否一键执行」（A-07）与「用户扩展点 / 映射可配置性」（A-08），再攻边界。
- [2026-09-23 · backup-archiver] 令：凡定时 / 批处理类立论，反方先攻「触发环境与运行时」（谁调度、什么机器、依赖与挂载点）再攻「保留 / 覆盖策略」（A-11/A-12）。
- [2026-09-23 · email-auto-reply] 令：凡「自动 + 保证无错」类立论，反方第一剑直插「误报 / 漏报代价不对称、测试夹具是否偷换真实分布」（A-13）。
