# 攻击库（attacks）

**反方质询的红队弹药库。** 每场抓到的新漏洞模式沉淀到这里；**新立论先撞库**——反方一开打就查本目录，命中的攻击模式优先使用并打「命中」标记。

> 首版 6 条从首场战报（`work/reports/xhs-product-copy.md`）提炼；A-07/A-08 由示范战 `desktop-file-sorter`、A-09/A-10 由 `paper-ref-extractor`、A-11/A-12 由 `backup-archiver`、A-13 由 `email-auto-reply` 入库（战报见 `work/reports/`）；A-14 由门控重构入库（门控攻击，非战报抓虫）。每条 = 攻击点｜问法｜最小反例。

## A-01 目标不可测
- 攻击点：目标里的形容词没定义「成」的判据。
- 问法：「做到什么状态才算成？给一个别人不看你也判得出来的标准。」
- 最小反例：按字面执行，AI 自认为成了，你说凭什么——验收无从落地。

## A-02 受众 / 渠道缺省
- 攻击点：没说给谁看、发在哪 → 语气与平台规则未定。
- 问法：「受众是谁？发在哪？符合那个平台的调性和字数吗？」
- 最小反例：同一份文案发小红书和公众号，一个像种草、一个像聊天，两头不是。

## A-03 红线空白
- 攻击点：只说了要什么，没说绝不能做什么。
- 问法：「哪些话绝对不能写？写了会怎样？」
- 最小反例：没有红线，AI 顺手写出医疗级宣称，你背锅。

## A-04 无交付结构
- 攻击点：只有「写一段」式的需求，不知道到底交几个文件、几个模块。
- 问法：「交什么？几个文件？每个文件里放什么？」
- 最小反例：AI 交付一坨，你也不知道该验收哪部分。

## A-05 验收主观
- 攻击点：验收标准靠感觉，不是可勾选的清单。
- 问法：「做完拿什么证明？逐条可打勾吗？」
- 最小反例：验收写「生动有趣」，AI 和你对「生动」的理解各执一词。

## A-06 平台合规
- 攻击点：忽略发布平台的硬性规则（如小红书的功效宣称）。
- 问法：「这个平台的禁用词 / 功效红线是什么？动了怎么办？」
- 最小反例：玩梗写得飞起，发稿前被平台限流或封。

## A-07 验收不可一键执行
- 攻击点：验收只说「给样例 / 自测」，没说怎么跑、样例在哪、谁配合造。
- 问法：「验收能不能用一条命令跑完？样例数据在哪、谁生成的？」
- 最小反例：立论写"用样例目录验证"，但夹具不存在、验证靠人肉比对——验收还是主观的。

## A-08 扩展点缺失
- 攻击点：交付物 / 配置没有给用户可改的点（映射、规则写死在代码里）。
- 问法：「用户想加一类型 / 改一条规则，改哪？动代码还是改配置？」
- 最小反例：品类→扩展名映射写死在脚本里，用户想加 epub→books 得改代码重跑。

## A-09 输入素材缺失
- 攻击点：任务跑依赖的语料 / 输入数据没给（"把我的论文 PDF 抽引用"——PDF 在哪？）。
- 问法：「你手头有没有真实物料？谁提供、有没有授权？」
- 最小反例：没有真语料，唯一验收手段"对着真实数据数成果"悬空——AI 只能自造反例自证清白。

## A-10 权威源无锚点
- 攻击点：格式 / 规范对齐类目标，判据只在看不见的权威源里，机器无法自动判定"对"。
- 问法：「'排对'的唯一裁判是谁？能不能把它变成机器可判定、可枚举的样例？」
- 最小反例：按 GB/T 7714 排参考文献，变体几十条，AI 每条自圆其说——验收退回人眼。

## A-11 不可逆 / 覆盖策略缺失
- 攻击点：同名列被覆盖、旧版不可逆丢失；只增不删则磁盘跑满。破坏性边界没写。
- 问法：「同名文件第二次跑会发生什么？旧版本你还有吗？清理动作有回滚吗？」
- 最小反例：每天备份同名报表，一天跑两次，第一次的版本被覆盖——备份丢了历史。

## A-12 触发与运行时未声明
- 攻击点：「每天跑」没说谁调度、什么机器、有没有依赖与挂载点，验收在真实环境跑不起来。
- 问法：「谁在什么时候调用它？运行环境、挂载点、依赖清单是什么？」
- 最小反例：脚本写好了，但机器没 Python / 共享盘没挂载 / 没人设定时任务——"漏跑"无法验收。

## A-13 验收偷换（夹具 ≠ 线上）
- 攻击点：用测试夹具的成绩冒充线上成绩；关键任务只报"平均正确率"，不区分漏 / 误代价。
- 问法：「夹具的集中度 = 真实分布吗？漏 / 误代价对称吗？分开计了吗？」
- 最小反例：50 条 mock 95% 正确，上线全月真实答错 40%；一条威胁邮件被自动回掉，代价远大于"平均正确率"算得出的数。

## A-14 许愿池反射（门控攻击）
- 攻击点：人类用「直接生成 / 你看着办」当门洞，想把缺席的架构丢给 AI 自填；AI 一旦代填，许愿池复燃。
- 问法：「你真要放行的是仪式还是架构？架构四要素你还没说——继续，缺哪个我点到哪个。」
- 最小反例：一句"直接生成"换来一坨用户验收不了、也不知道架构的输出——绕门控一圈又回到许愿池。
