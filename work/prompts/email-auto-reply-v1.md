# 客户邮件自动回复 · email-auto-reply（定稿 v1）

| 要素 | 内容 |
| --- | --- |
| 任务 | 自动回复客服邮箱里的常见咨询；不确定的一律转人工，**绝不允许"该转人工的却自动回"** |
| 目标 | 可测：物流 / 退换 / 发票三类高置信咨询一分钟内自动回复；**漏转人工率必须 = 0**（威胁 / 索赔 / 多主题 / 非中文必交人）；高置信中线自动回复正确率 ≥95% |
| 约束 / 红线 | 不泄露客户信息（含日志脱敏：不落盘正文、不用客户邮件训练）；绝不自作主张承诺赔偿 / 升级；异常邮件零自动回复 |

## 交付物（改动落点）

1. `mailbot/poller.py` —— 收信轮询：只读来源收件箱，标记已处理。
2. `mailbot/classifier.py` —— 意图分类，输出 `{class, confidence, is_boundary}`；`is_boundary=True` 或置信不足 → 强制走转人工，不出模板。
3. `mailbot/reply_templates.yaml` —— 三类高置信回复模板（占位符校验：缺失字段不得发送）。
4. `mailbot/escalate.py` —— 转人工 + 邮件正文脱敏后落库。
5. `config.yaml` —— 可配：邮箱接入、三个意图的触发置信阈值、转人工队列。
6. `tests/cases/` —— 60 条标注用例（50 常见 + 10 边界：威胁 / 垃圾 / 双主题 / 非中文），字段 = `{输入, 标注, 预期动作}`。
7. `verify.py` —— 一键自检：对 60 条用例跑 mock，分别断言 `漏转人工率 == 0` 与高置信正确率 ≥95%。

## 验收标准（做完拿什么证明）

- [ ] `python verify.py` 全绿：60 例中 0 条「该转人工却自动回」，高置信中线正确率 ≥95%
- [ ] 单独列出 10 条边界用例的原样转人工记录，可人工复查
- [ ] 日志抽查：正文不落盘、无训练留存
- [ ] 换一个收件入口（改 `config.yaml`）无需改代码即生效
