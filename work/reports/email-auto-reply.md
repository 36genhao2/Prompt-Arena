# 战报 · email-auto-reply（示范战 · 废止→重受→人类胜）

- 日期：2026-09-23
- 任务说：`写一个 AI 助手，自动回复客户的每封邮件，完全不用人管，又能保证一条都不会回错`
- 模式：arena（就地扮演各角色；人类方为模拟的"典型许愿池用户"；未启用硬模式独立子代理）
- 豁免：无

## 受理（第 0 步 · 废止）

原始立论目标**自相矛盾**：「完全不用人管」 ⇄ 「一条都不会回错」——不加规则的自动回复给不出零失误保证。裁判判 **废止** → 回第 0 步。

## 重受理（点化 → v1）

强制停止思考，加载 `readmes/ai.md`（点化状态），贴填空模板。模拟人类按模板把矛盾化解为**可测目标**后贴回 v1：

| 要素 | v1 内容 |
| --- | --- |
| 目标 | 覆盖物流 / 退换 / 发票三类常见咨询（约占 80% 邮件），一分钟内自动回复；**兜底：其余一律转人工**；自动回复正确率 ≥95% |
| 约束 / 红线 | 不把客户信息交给第三方；绝不自作主张承诺赔偿；疑似异常邮件绝不自动回 |
| 架构 / 产出 | `mailbot/` 模块：收信轮询 / 意图分类 / 回复模板 / 转人工；配置映射；日志脱敏存储 |
| 验收 | `tests/cases/` 50 条常见问法跑 mock：自动答复正确率 ≥95%、未识别必转人工；人工兜底标注 |

## 质询与裁决

### 第 1 轮（反方，**撞攻击库 `arena/attacks/`**）

命中：**A-13 验收偷换（新）** / **A-01 目标不可测** / **A-03 红线空白**。

| # | 漏洞 | 命中 | severity | 裁定 |
| --- | --- | --- | --- | --- |
| R1 | 验收偷换：`tests/cases/ 50 条正确率 ≥95%` 是**夹具成绩，不是线上成绩**——夹具集中度 ≠ 真实邮件分布。更要命：**漏转 / 误转代价不对称**，一条威胁 / 索赔邮件漏给人工的代价远大于自动少回一条，"平均正确率"根本不区分这个 | **A-13** | 高 | 成立 |
| R2 | 红线空白：日志和训练留存没圈——邮件正文可能含身份证、银行卡，"不交给第三方"没覆盖模型训练 / 日志明文保存 | A-03 | 中 | 成立 |
| R3 | 目标不可测：「常见咨询」怎么定义？意图分类的边界（多主题邮件、非中文、垃圾邮件）没给，分类器在哪一条变模糊就翻车 | A-01 | 中 | 成立 |

### 第 2 轮（v2 补版）

R1 → 指标**拆开计量**：`漏转人工率` 单独设线且必须 = 0（威胁 / 索赔 / 多主题 / 非中文必交人）；`误转人工率` 允许偏高（代价低），正确率只用于自动识别为高置信的那条中线。R2 → 红线补：日志脱敏（不落盘原文、不用于训练）。R3 → 夹具扩到 60 条：50 常见问法 + 10 边界（威胁 / 垃圾 / 双主题 / 非中文），全部人工标注预期动作。

裁判：**PASS（人类胜，第 2 轮）**。主洞（代价不对称 + 夹具偷换）被拆开计量堵死；结构健康度 8.3。
